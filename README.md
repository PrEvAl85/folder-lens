# folder-lens

Лёгкое кросс-платформенное приложение для инвентаризации папок: показывает все файлы в выбранной папке и всех подпапках, сгруппированные по типам (расширениям), и отдельно — список пустых подпапок.

Удобно, когда файлы «зарыты» в глубоких цепочках подпапок: плоский список с путями сразу показывает, где что лежит.

## Возможности

- Сканирование выбранной папки рекурсивно (с прогрессом и кнопкой «Стоп»).
- Группировка всех файлов по расширению: количество и суммарный размер по типу.
- Плоский список файлов выбранного типа: имя, размер, дата изменения, путь.
- Отдельная секция «Пустые папки» — папки без файлов, клик открывает в проводнике.
- Поиск по типу и по имени файла, сортировка (имя / размер / дата / путь).
- Перемещение файлов типа в выбранную папку: без перезаписи (дубли получают суффикс «(1)»), с отменой последнего перемещения.
- Экспорт инвентаря в CSV (с BOM, разделитель `;`) или JSON.
- Открытие файла и «Показать в проводнике» по клику.

## Технологии

- [Tauri 2](https://tauri.app) (Rust + системный WebView) — Windows / macOS / Linux.
- Frontend — чистый HTML/CSS/JS без фреймворков.
- Основные Rust-крейты: `walkdir`, `serde`, `dunce`, `chrono`, `tauri-plugin-dialog`, `tauri-plugin-opener`.

Бинарник ~10 МБ, память — минимальна.

## Сборка и запуск

Требования: [Rust](https://rustup.rs) (stable), [Node.js](https://nodejs.org) ≥ 18, системные зависимости [Tauri](https://tauri.app/start/prerequisites/).

```sh
npm install
npm run tauri dev     # разработка
npm run tauri build   # релизная сборка (msi/nsis/deb/appimage/…)
```

## Тесты

```sh
cd src-tauri && cargo test
```

Покрытие: сканирование и группировка, отмена сканирования, перемещение без перезаписи, откат перемещения, экспорт CSV/JSON.
